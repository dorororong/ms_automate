# Solar Pro 4 간소화 및 속도 측정

측정일: 2026-09-08. 모델 `solar-pro4`, `reasoning_effort=none`.

현재 기본값은 `semantic-v4-compact`이다. 고정 규칙은 1,517자이며,
제출 예제 요청에서 메시지·사용자 정보 포함 입력은 4,245자 → 1,633자,
response_format 전체는 2,969자 → 1,583자로 줄었다. API가 보고한 해당
예제의 입력 토큰은 1,657 → 629이다. 문자 수와 토큰 수는 다르다.

## 구현

- API 필수 항목 필드: 22개 → 12개. 날짜·조건·반복은 필수로 유지한다.
- 선택 필드는 필요할 때만 생성한다. 빈 설명·위치·알림·체크리스트는 로컬 기본값으로 복원한다.
- 근거는 짧은 원문 1개로 받고, 내부 group_id·source_state 기본값 등은 코드에서 채운다.
- 관련 날짜는 role/raw_text 두 필드로 받는다. 상세 정규화 날짜·시각은 생성하지 않고
  원문을 보존한다. 실제 등록 시각은 at/due/due_time을 사용한다.
- 작은 JSON Schema(`strict=false`)와 로컬 필수 필드·타입·열거형 검증을 함께 사용한다.
  서버의 엄격 모드에 의존하지 않으며, 부적합 응답은 기존 재시도/오프라인 전환 경로로 보낸다.
- 기존 Calendar 시각 검증, 조건부 기본 미선택, 중복 조회 실패 시 등록 보류는 유지한다.
- API 클라이언트는 시도 종료 시 닫는다. UI·DB 내보내기용 WorkItem 구조는 유지한다.

## 최종 실측

합성 메시지 4종(제출, 토익 모집, 복합 업무, 완료 안내)을 각각 2회 실행했다.
기존 버전은 `eb0f898`이며, 최종안은 후속 실행했다. 같은 시간대의 완전한 무작위
대조시험이 아니므로 차이 전부를 코드 효과라고 단정할 수 없다.
큐 대기·파일 추출·UI·Outlook 시간은 포함하지 않는다.

| 항목 | 기존 8회 | 최종 간소화 8회 |
|---|---:|---:|
| 평균 | 12.178초 | 4.606초 |
| 중앙값 | 15.421초 | 4.308초 |
| 5초 이내 | 3/8 | 4/8 |
| API/파싱 성공 | 8/8 | 8/8 |
| 핵심 의미 판정 통과 | 7/8 | 7/8 |

평균은 약 62% 감소했다. 단, 빠른 완료 안내 2회를 제외한 **실제 업무 추출 6회**의
평균은 기존 15.894초 → 최종 5.595초이며, 최종 5초 이내는 2/6회다.
따라서 매 요청 5초 목표는 아직 달성하지 못했다.

| 최종안 메시지 | 1회 | 2회 |
|---|---:|---:|
| 제출 | 8.051초 | 2.569초 |
| 토익 모집 | 7.270초 | 2.418초 |
| 회의·제출·반복 지도 | 6.046초 | 7.213초 |
| 완료 안내 | 2.020초 | 1.262초 |

최종 8회에는 재시도가 없었으며, API usage의 reasoning_tokens는 모두 0이었다.
짧은 출력도 수 초씩 변하므로 출력 축소만으로 5초를 보장할 수 없다.
서버 대기와 생성 속도는 개별 계측하지 않았으므로 지연의 내부 원인은 확정하지 않는다.

의미 판정은 항목 수뿐 아니라 제출 기한·시각, 모집의 조건부/행사 문맥, 복합 업무의
회의 시각·제출일·반복 여부를 검사한다. 최종안의 토익 모집 2회차는 신청 1건을
유지했지만 모호한 '당일' 마감을 행사일 8월 23일로 확정해 실패했다. 조건부 항목이라
기본 선택은 해제된다. 전체 의미 정확도나 실제 32건 엑셀의 합격률로 해석하면 안 된다.

## 검증 및 측정 자료

- 기존 로컬 자가 점검 27/27, 새 축약 계약 테스트 7/7, compileall 통과.
- 실제 Outlook 등록·수정·삭제는 수행하지 않았다.
측정 자료는 `benchmarks/`에 실험 순서대로 둔다.

- `01_baseline_vs_8fields.json`: 기존 방식과 초기 8필드 실험의 교차 비교.
- `02_10fields.json`: 중간 10필드 실험.
- `03_12fields.json`: 최종 12필드 결과, 호출별 토큰·시간·핵심 필드.

8필드 실험은 평균 4.155초였지만 의미 판정 5/8로 관련 날짜·반복 정보가 누락됐다.
10필드 실험은 의미 판정 6/8이었다. 최종안은 날짜와 반복의 필수 출력을 복원했다.
측정 JSON에는 합성 사례의 결과만 포함되며 개인 메시지·API 키는 저장하지 않는다.

재측정은 API 비용이 발생한다:

```powershell
python -m unittest test_compact_extraction -v
python selftest.py --offline
python benchmark_latency.py --repeats 2 --baseline eb0f898
```

추가 개선 판단에는 실제 32건에 대한 새 의미 채점, 다회 반복 측정, 첫 응답까지의
대기/전체 생성 시간 분리 계측이 필요하다. 스트리밍은 진행 표시를 앞당길 수 있지만,
검증된 최종 JSON을 기다리는 현재 검토창의 완료시간을 보장하지 않는다.
